#### ***Habit Tracker (Full-Stack)***



A habit tracker with user accounts. Each person logs in and sees only their own habits, daily check-ins and streaks.



&#x20;***Features***

\- Sign up, log in and log out

\- Passwords are salted and hashed, never stored as plain text

\- Login sessions kept in a cookie

\- Add, delete and tick habits for today

\- Streak counter for days in a row

\- Each user can only see and change their own habits

\- Dark mode

\- Data stored in a SQLite database



***Built with***

\- HTML, CSS, JavaScript

\- Node.js and Express

\- SQLite



***TRY it on your computer***

1\. Install Node.js

2\. Clone this repository

3\. Run `npm install`

4\. Run `node server.js`

5\. Open http://localhost:3000



***What I learned***

\- Building a REST API with Express

\- Designing database tables and linking habits to users

\- Hashing passwords and handling login sessions

\- Connecting a front end to a back end with fetch

\- Working with Git branches, one feature per branch
